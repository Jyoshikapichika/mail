# MailMate – Pattipati Lalitha (Educational Demo)

An educational, responsive web demonstration of a modern email inbox interface built for college presentation.

> **Disclaimer:** This project is strictly an educational UI demonstration. It is not an official NPTEL portal, examination service, or affiliated with Google LLC or NPTEL / SWAYAM.

---

## 🎯 Features
- **Responsive Web & Mobile Layout:** Gmail-inspired user interface with Primary, Promotions, Social, and Updates categories.
- **NPTEL Examination Notification:** Sample email detailing candidate registration, examination centre, shift timing, and seating arrangement.
- **Hall Ticket PDF Integration:** Embedded attachment card with download and in-browser preview options for the official hall ticket.
- **PWA Ready:** Installable on Android and desktop with offline asset caching via Service Worker.
- **Complete Email Workflow:** Interactive inbox, search filter, star toggle, compose modal, and reply/forward actions.
